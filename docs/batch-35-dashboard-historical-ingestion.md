# دفعة 35 — أساس أرشيف ملفات Dashboard التاريخية

**الفرع:** `integration/unified-test-2026-11-19`  
**نقطة البداية:** `c26e3a587dbf2394502db81aa3f2ce34b1ef64ee`

## ما تغير
- إضافة أرشيف Excel محلي مستقل لملفات المتابعة السنوية/الشهرية، والأسعار والتكلفة، وتفصيل التحاليل لعامي 2025 و2026.
- فصل التخزين بمفتاح مركب من Tenant ID ونوع الملف؛ تغيير المعمل في لوحة المالك يعرض أرشيف المعمل المحدد فقط.
- فحص نوع الملف وحجمه وأوراق العمل الأساسية قبل الحفظ.
- استعراض أسماء الأوراق وحجم الملف، وحذف النسخة المحلية لنوع محدد.
- ربط الأرشيف بلوحة المالك دون تغيير استعلامات Supabase الحية أو جداول التشغيل.

## حدود مهمة
- الملفات تحفظ في IndexedDB على المتصفح الحالي فقط؛ هذا ليس Backup سحابيًا ولا ينتقل تلقائيًا إلى جهاز آخر.
- لم تُنقل بعد معادلات التحليلات الـ18 القديمة إلى محرك التحليل الجديد؛ هذه الدفعة تؤسس مصدرًا تاريخيًا معزولًا يمكن ربط التقارير به.
- لا يتم رفع ملفات Excel إلى Supabase ولا إدخال صفوفها إلى جداول المرضى/الزيارات.
- لا تغيير في قاعدة البيانات أو RLS أو الأسرار أو Offline outbox.

## التحقق
- أضيف اختبار static لعزل الأرشيف المحلي عن استعلامات السحابة.
- يلزم تشغيل GitHub Actions على commit الناتج؛ لا يوجد ادعاء باختبار متصفح حي في هذه الدفعة.
