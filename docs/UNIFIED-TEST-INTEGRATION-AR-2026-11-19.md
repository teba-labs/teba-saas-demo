- `STAFF_INVITE_ALLOWED_ORIGINS`
- `ATTACHMENT_ALLOWED_ORIGINS`
- `PORTAL_ALLOWED_ORIGINS`
- `PORTAL_HASH_SECRET` (قيمة عشوائية قوية تحفظ سرًا على الخادم)
- `REPORT_ALLOWED_ORIGINS`

يجب أن تحتوي قيم Origins على أصل الموقع الدقيق فقط، مثل `https://example.com` من دون مسار. لا تضع أي secret في Git أو كود المتصفح. لا توجد أداة إدارة أسرار متاحة في اتصال Supabase الحالي، ولذلك لم تُكتب هذه القيم أو تُخمن.

## الاختبارات
- GitHub Actions: 157 اختبارًا ثابتًا ناجحًا، صفر فشل.
