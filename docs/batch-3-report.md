# Batch 3 — Catalog, Reception and Expenses repositories

Implemented as data-access foundations, not yet wired into the legacy HTML screens.

- Catalog reads active tests, current prices and active parameter definitions.
- Catalog upsert uses tenant scope; price history is written separately and remains owner-only by database policy.
- Reception patient lookup is scoped to tenant + branch; patient creation requires both.
- Visit creation requires an open branch workday and stores staff attribution.
- Adding a visit test relies on the database trigger to snapshot price and technical details.
- Billing stores gross and discount values; net total is generated by PostgreSQL.
- Payments and expenses call the schema's RPC functions, not direct table writes, preserving idempotency and ledger triggers.

Not yet verified: live browser requests, role enforcement, end-to-end UI flows, and offline replay. No production connection is configured.
