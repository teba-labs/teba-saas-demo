# ترقية تطبيق Windows وتحديثاته — Taiba Smart Lab

## النسخة الحالية

- إصدار التطبيق: 1.0.2
- Electron: 45.5.0 (مثبّت بإصدار محدد، وليس نطاقًا عائمًا)
- منصة التوزيع: Windows x64 / NSIS
- قناة التحديث: GitHub Releases للمستودع العام teba-labs/teba-saas-demo
- المشروع السحابي: hgqwpykeazuzceeiumjg؛ لا توجد Migration أو تغييرات بيانات ضمن ترقية سطح المكتب.

## سلوك التحديث داخل البرنامج

1. يفحص البرنامج وجود إصدار جديد بعد بدء التشغيل، ثم يعيد الفحص كل 6 ساعات.
2. لا يبدأ تنزيل أي تحديث قبل ضغط المستخدم على «تنزيل التحديث».
3. بعد اكتمال التنزيل والتحقق، يعرض البرنامج خيار إعادة التشغيل والتحديث أو المتابعة.
4. إذا اختار المستخدم المتابعة، يثبت التحديث عند إغلاق البرنامج لاحقًا.
5. تعذر الاتصال بالإنترنت لا يعطل التشغيل أو العمل دون اتصال ولا يحذف البيانات المحلية.
6. لا تُحمّل الإصدارات التجريبية، ولا يُسمح بالرجوع التلقائي إلى إصدار أقدم.

## إصدار تحديث جديد

- راجع إصدار Electron المستقر الجديد، فترة دعمه، متطلبات Windows، والتغييرات الكاسرة.
- حدّث Electron وelectron-updater وأدوات البناء، ثم اختبر التثبيت والترقية والبيانات المحلية.
- ارفع رقم إصدار التطبيق في package.json.
- أنشئ إصدار GitHub Release بعلامة v<version> بعد اعتماد الاختبارات.
- يجب أن تحتوي أصول الإصدار على ملفات NSIS وملف latest.yml وملفات blockmap التي ينشئها electron-builder.
- لا تنشر تحديثًا رئيسيًا تلقائيًا دون موافقة مالك المنتج.

## المراقبة

- electron-upstream-watch.yml يفحص أحدث إصدار stable أسبوعيًا.
- عند ظهور إصدار أحدث، ينشئ Issue للمراجعة بدل ترقية التطبيق أو نشره تلقائيًا.
- البرنامج المثبّت نفسه يفحص قناة GitHub Releases كل 6 ساعات ويطلب موافقة المستخدم قبل تنزيل التحديث.

## الاختبارات المطلوبة من مالك المنتج

- تثبيت نظيف على Windows 10 x64 وWindows 11 x64.
- تشغيل التطبيق، تسجيل الدخول، الطباعة، والعمل دون إنترنت.
- التحقق من بقاء IndexedDB وOutbox وOPFS والإعدادات المحلية بعد التثبيت.
- تجربة التحديث بعد نشر Release فعلي، مع اختيار «لاحقًا» ثم إغلاق التطبيق للتحقق من التثبيت.
- التأكد من عدم فقد البيانات عند فشل تنزيل التحديث أو انقطاع الإنترنت.

## حدود التحقق

نجاح GitHub Actions على مشغّل Windows يثبت البناء والاختبار داخل صورة Windows المستضافة، لكنه لا يثبت التوافق على كل جهاز Windows 10/11 فعلي. كما أن نشر التحديثات يتطلب إصدار GitHub Release يحتوي على ملفات التحديث؛ مجرد دمج الكود لا ينشر تحديثًا للمستخدمين.
