# دفعة 39 — فصل فترة التحليل التاريخي عن التشغيل الحي

- أضيفت دالة `findLatestHistoricalPeriod` لاكتشاف آخر شهر له إيراد فعلي في ملف Excel التاريخي.
- أضيف حقل فترة مستقل للتحليل التاريخي؛ لم يعد التقرير التاريخي يستخدم محدد شهر التشغيل الحي.
- عند فتح الأرشيف لأول مرة، يختار النظام آخر شهر تاريخي متاح تلقائيًا. وبعد ذلك يستطيع المستخدم اختيار أي شهر تاريخي مستقل.
- عند تحميل ملف جديد يعاد تحديث التقرير التاريخي من الملف المحفوظ.
- الملفات: `modules/dashboard/historical-analysis.js`, `assets/js/dashboard-history.js`, `app/dashboard.html`, `tests/unit/historical-analysis.test.mjs`.
- الاختبار الحسابي لاكتشاف الفترة أضيف؛ لم يُشغّل فعليًا بعد. لا اختبار متصفح حي.
